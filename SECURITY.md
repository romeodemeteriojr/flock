# Security

Please do not report security problems in public issues.

Report them privately through GitHub: on this repository's **Security** tab,
choose **Report a vulnerability**. Say what you found, how to reproduce it, and
which version you used. You will get an answer as soon as possible.

Only the latest release is supported. How Flock protects logins and data is in
[docs/security.md](docs/security.md).
